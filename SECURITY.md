# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/lmgarret/karakept-kmp/security/advisories/new)
instead. Include the affected version, the platform (Android or desktop), and steps to reproduce.

You can expect an acknowledgement within a week. Once a fix is released, the advisory is published
with credit to the reporter unless you ask otherwise.

Vulnerabilities in the Karakeep server itself belong upstream, at
[karakeep-app/karakeep](https://github.com/karakeep-app/karakeep/security).
