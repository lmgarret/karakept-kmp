From ui/screens/BookmarkViewerScreenModel.kt (line 240):
```kotlin
// Public method — parses html if not cached, caches result, returns Document
fun getCachedOrParseDocument(bookmarkId: Long, html: String): com.fleeksoft.ksoup.nodes.Document?
```

Key insight: HtmlContent sanitizes raw HTML via HtmlSanitizer.sanitize() into processedHtml.
NativeHtmlRenderer receives processedHtml (sanitized), NOT raw HTML.
getCachedOrParseDocument must be called with the SANITIZED html so the cached Document matches.
Solution: pass a lambda `(String) -> Document?` that wraps getCachedOrParseDocument(bookmarkId, sanitizedHtml).
The lambda is called inside NativeHtmlRenderer where the sanitized html is available.
