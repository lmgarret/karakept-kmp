<objective>
Eliminate race conditions in MainScreenModel initialization and bookmark list mutations.

Purpose: The init block relies on implicit coroutine ordering that is fragile and unauditable. The _accumulatedBookmarks MutableStateFlow has 27 read-modify-write sites from multiple concurrent coroutines with no synchronization, risking lost updates. This plan makes init explicit via a state machine and protects all mutations with a Mutex.

Output: MainScreenModel.kt with InitState sealed class, logged state transitions, and mutex-protected bookmark mutations. BookmarkActionsRepository.kt with vestigial comment cleaned up.
</objective>

/**
 * Thread-safe mutation of _accumulatedBookmarks.
 * All code that reads-then-writes _accumulatedBookmarks MUST use this helper.

    bookmarksMutex.withLock {
        _accumulatedBookmarks.value = transform(_accumulatedBookmarks.value)

}
