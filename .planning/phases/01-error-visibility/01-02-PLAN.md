Replace every `!!` operator with a context-appropriate safe null pattern. The replacement strategy depends on context:

**CRITICAL — Composable functions:** Do NOT use `?: return` at the top of a composable function as it would skip rendering subsequent composables. Instead, wrap the dependent section in `?.let { }` or use a local `val x = nullable ?: return@ScopeLabel` within a lambda scope.

**File-by-file replacements:**

**MainScreen.kt — lines 1119-1144 (the big cluster):**
The block is inside `if (selectedBookmarkForActions != null) { ... }`. Smart cast does not apply because `selectedBookmarkForActions` is a mutable `var` (recomposition can change it). Fix: immediately capture to a local val at the start of the block:
```kotlin
if (selectedBookmarkForActions != null) {
    val bookmark = selectedBookmarkForActions ?: return@let // or ?: return@run
    BookmarkActionsMenu(
        bookmark = bookmark,
        ...
        onAction = { action ->
            when (action) {
                is BookmarkAction.ToggleArchive -> screenModel.toggleBookmarkArchive(bookmark)
                is BookmarkAction.ToggleFavorite -> screenModel.toggleBookmarkFavorite(bookmark)
                // ... all other uses of selectedBookmarkForActions!! become bookmark
            }
        }
    )
}
```
