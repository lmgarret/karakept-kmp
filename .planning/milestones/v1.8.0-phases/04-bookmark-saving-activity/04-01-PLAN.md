<objective>
Fix the Android share-target bookmark saving flow by replacing the broken ShareActivity-to-MainActivity delegation with a self-contained BookmarkSavingActivity.

Purpose: Resolve two bugs -- (1) user gets trapped in the bookmark viewer with no back route to the list after saving via share target (#158, SAVE-01), and (2) sharing a second URL reuses stale state from the first save (#159, SAVE-02).

Output: A working BookmarkSavingActivity with singleTask launch mode, proper back stack navigation, retry/close error handling, and clean removal of the old ShareActivity delegation pattern.
</objective>

```kotlin
package com.karakept.app

import android.content.Intent
import android.os.Bundle
import androidx.activity.ComponentActivity
import androidx.activity.compose.setContent
import androidx.activity.enableEdgeToEdge
import androidx.compose.runtime.Composable
import androidx.compose.runtime.collectAsState
import androidx.compose.runtime.getValue
import androidx.compose.runtime.key
import androidx.compose.runtime.mutableIntStateOf
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.setValue
import cafe.adriel.voyager.navigator.Navigator
import cafe.adriel.voyager.transitions.SlideTransition
import com.karakept.app.data.model.AccentColor
import com.karakept.app.data.model.ThemeMode
import com.karakept.app.data.repository.SettingsRepository
import com.karakept.app.ui.screens.ShareBookmarkScreen
import com.karakept.app.ui.theme.AppTheme
import org.koin.compose.koinInject

class BookmarkSavingActivity : ComponentActivity() {
    private var sharedUrl by mutableStateOf<String?>(null)
    private var intentKey by mutableIntStateOf(0)

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        sharedUrl = extractUrlFromIntent(intent)

        setContent {
            key(intentKey) {
                val url = sharedUrl
                if (url != null) {
                    BookmarkSavingContent(url = url, onClose = { finish() })
                } else {
                    finish()
                }
            }
        }
    }

    override fun onNewIntent(intent: Intent) {
        super.onNewIntent(intent)
        setIntent(intent) // Pitfall 7: update stored intent reference
        sharedUrl = extractUrlFromIntent(intent)
        intentKey++ // Forces full recomposition, destroying Navigator + all remembered state
    }

    private fun extractUrlFromIntent(intent: Intent): String? {
        if (intent.action != Intent.ACTION_SEND || intent.type != "text/plain") return null
        val sharedText = intent.getStringExtra(Intent.EXTRA_TEXT) ?: return null
        val urlRegex = "(https?://[\\w-]+(\\.[\\w-]+)+(:\\d+)?(/[^\\s]*)?)".toRegex()
        return urlRegex.find(sharedText)?.value ?: sharedText
    }
}

@Composable
private fun BookmarkSavingContent(url: String, onClose: () -> Unit) {
    val settingsRepository = koinInject<SettingsRepository>()
    val themeMode by settingsRepository.themeMode.collectAsState(initial = ThemeMode.SYSTEM)
    val accentColor by settingsRepository.accentColor.collectAsState(initial = AccentColor.PURPLE)

    AppTheme(themeMode = themeMode, accentColor = accentColor) {
        Navigator(ShareBookmarkScreen(url = url, onClose = onClose)) { navigator ->
            SlideTransition(navigator)
        }
    }
}
```

Key design notes:
- `key(intentKey)` wraps the entire Compose tree. When `intentKey++` happens in `onNewIntent`, the Voyager `Navigator` and all `remember` blocks are destroyed and recreated, guaranteeing fresh state (per D-05).
- `BookmarkSavingContent` sets up its own `AppTheme` so theming works independently of `MainActivity`.
- The URL regex is copied verbatim from the existing `ShareActivity.handleIntent`.
- `enableEdgeToEdge()` ensures transparent status/nav bars consistent with `MainActivity`.
- `onClose` callback is passed into `ShareBookmarkScreen` so the error Close button can call `activity.finish()`.

Note: `ShareBookmarkScreen` needs a new `onClose` parameter -- this is added in Task 2. The `ShareBookmarkScreen` constructor will change from `data class ShareBookmarkScreen(val url: String)` to `data class ShareBookmarkScreen(val url: String, val onClose: (() -> Unit)? = null)`. The default `null` keeps backward compatibility for any other call sites.
