**Step 1 — Create shared helper in ActionSnackbarManager.kt (per UX-01 shared helper requirement, addresses review concern: "Establish shared UndoableSnackbar pattern/helper if 3+ sites use it"):**

Add a `CoroutineScope` extension function at the bottom of `ActionSnackbarManager.kt` that encapsulates the "perform action, then show undo snackbar" pattern used by 4+ call sites:

```kotlin
/**
 * Shared helper for the undoable action pattern.
 * Performs [action] immediately, then shows an undo snackbar.
 * If the user taps Undo, [onUndo] is called to reverse the action.
 *
 * Usage: scope.undoableAction(snackbarManager, "Archived") { screenModel.toggleBookmarkArchive(bm) }
 */
fun CoroutineScope.undoableAction(
    snackbarManager: ActionSnackbarManager,
    message: String,
    onUndo: suspend () -> Unit
) {
    launch {
        snackbarManager.showSnackbarWithUndo(message, onUndo)
    }
}
```

This is intentionally minimal — it wraps the `scope.launch { snackbarManager.showSnackbarWithUndo(...) }` boilerplate that every call site repeats. All call sites below should use `scope.undoableAction(snackbarManager, msg) { reverseAction() }` instead of the raw `scope.launch { ... }` pattern.

Add the required import at the top: `import kotlinx.coroutines.CoroutineScope` and `import kotlinx.coroutines.launch`.

**Approach (per D-07, D-08):** The batch methods in `MainScreenModelBatch.kt` fire API calls and update local state. The undo must re-call the reverse batch method. Since batch methods call `clearSelection()` at the end, the undo lambda needs to work with the captured bookmark list directly. The cleanest approach: add snackbar calls in the batch method wiring sites (MainScreenScaffoldContent.kt and MainScreen.kt), capturing count before the call.

**However**, batch methods are `fun MainScreenModel.batchArchive()` — they get selected bookmarks internally and clear selection. For undo to work, we need to either:
- (a) Make batch methods return the affected bookmarks, or
- (b) Capture `getSelectedBookmarks()` before calling the batch method and use that in the undo lambda.

Choose approach (b) since it avoids changing batch method signatures. `getSelectedBookmarks()` is `internal` so accessible from the same package.
