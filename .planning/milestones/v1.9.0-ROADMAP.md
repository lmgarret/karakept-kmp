## Milestone Summary

**Total new tests:** 201 (60 + 28 + 25 + 53 + 22 + 7 + 6)
**Coverage improvement:** ~40% → ~75-80% business logic

**Key Decisions:**

- FakeDataStore uses MutableStateFlow + Mutex for thread-safe atomic updates matching real DataStore semantics
- Used UnconfinedTestDispatcher + toList() for emission-counting deduplication tests (Phase 09)
- Real-object pattern for extension functions: when a class has extension functions accessing internal members, construct a real instance with mocked dependencies rather than mocking the class (Phase 08-03)
- Plain runTest {} (not runTest(testDispatcher)) for BookmarkActionController tests since executeAction wraps in Dispatchers.IO internally
- Internal top-level function extraction for composable logic to enable direct import in commonTest without Compose runtime (Phase 10-01)
- Robolectric assertExists/assertDoesNotExist are member functions of SemanticsNodeInteraction in CMP, not top-level imports (Phase 10-02)

**Issues Resolved:**

- Git submodule `karakeep-upstream` needed initialization in worktrees for OpenAPI generation
- JDK 25 incompatible with Gradle — JDK 21 required (documented in memory)

**Issues Deferred:**

- Robolectric 4.14 ModalBottomSheet click bug (performClick() silently fails inside bottom sheets on SDK 29-34) — upgrade to 4.15.1 before writing bottom sheet tests

**Technical Debt Incurred:**

- None — all tests exercise real production code with no stubs
